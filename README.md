# liforra-tool

> **Warning, this is fully Vibe Coded. Tested by a Human, here be dragons.**

A Wails (Go + TypeScript) desktop app that takes a refurbished PC from "no
GLPI entry" to "fully entered and finished" in [GLPI](https://glpi-project.org/),
the open-source IT asset management system. Built for a specific
organization's refurbishment workflow, but the approach (hardware detection,
GLPI catalog matching/creation, USB-stick report intake, spec-sheet
generation) is generic enough to be a useful reference for anyone scripting
against GLPI's REST API.

## What it does

- Detects the running machine's hardware (CPU, RAM, disks, GPU, battery
  health, OS) and cross-references it against GLPI's manufacturer/model/type/
  component catalogs — creating missing catalog entries when authorized to.
- Reads erase certificates, test reports, and spec sheets off a USB stick
  (as produced by disk-wipe/test tooling) and attaches them to the right
  GLPI Computer record.
- Before showing a freshly detected device, checks GLPI by serial number for
  an existing record and offers to edit it instead of creating a duplicate —
  GLPI's own data takes priority over the fresh hardware scan when the two
  disagree.
- A device-check ("Prüfen") page: verifies USB-stick reports belong to the
  device in hand, cross-checks GLPI's record for the device, flags problem
  devices/drivers, and can mark a device as checked (technician/group/
  location) with one click.
- Ships its own installer (`install.exe`) and uninstaller, both usable
  offline — everything is embedded, no network access required to install.
- An optional self-hosted update/build server (`cmd/buildserver`) for
  distributing new versions to already-deployed installs.

## Getting started

1. `cp internal/config/config.go.example internal/config/config.go` and fill
   in your GLPI instance's OAuth client ID/secret and v1 App-Token (GLPI
   admin → Setup → OAuth clients / Setup → General → API).
2. `go generate ./... ` isn't needed; Wails bindings are generated by the
   Wails CLI itself — install it per
   [wails.io](https://wails.io/docs/gettingstarted/installation).
3. `wails dev` for live development, `wails build` for a production binary.
4. For the standalone installer, see `cmd/installer/` — it embeds a built
   `liforra-tool.exe` + `uninstall.exe` and needs those payload files in
   place (`cmd/installer/payload/`) before building.
